# Lillith Author Workflow

This document is the product-level workflow reference for Lillith Studio.

The app is workflow-driven, not wizard-driven. A project should always answer:

- what this book is;
- what phase it is in;
- what artifacts already exist;
- what remains unresolved;
- what the best next action is;
- which existing workspace should be opened to do that work.

Workflow phases are soft guidance. They can be revisited, deferred, or skipped when the project does not need them.

## Early workflow

1. Project Creation
2. Idea Capture
3. Creative North Star
4. Discovery
5. Character Foundations
6. Story Architecture Foundations
7. Drafting Readiness

These phases produce a Project Brief, Creative North Star, discovery notes, unresolved decisions, and a clear recommendation for the next useful action.

## Core workflow objects

- Workflow phase: a stage in the author journey.
- Workspace: the tool used to do the work.
- Artifact: a durable record created by the workflow.
- Milestone: a meaningful checkpoint.
- Decision: an open question that can be resolved later.
- Recommendation: the next best action, explained.
- Publishing checklist item: a later-stage production/readiness check with evidence, status, and blocking rules.

## Later workflow

The publishing pipeline remains a separate operational workspace, but it is connected to the same project memory and artifact trail.

Publishing phases currently cover:

- Development
- Continuity
- Character Voice
- Narrative Weight
- Trust the Reader
- Proof and Integrity
- Production
- Cover
- Metadata
- Preview QA
- Publication
- Marketing
- Archive

These phases are intentionally soft-guided. A project can be ready for one format and not another. Creative work remains editable until the user chooses to publish.

## Workflow philosophy

- Reduce cognitive load.
- Keep state local-first.
- Preserve existing tools and surfaces.
- Explain why the app recommends a next step.
- Never hide unresolved work behind a score alone.
- Never silently overwrite manuscript text.

## Current implementation boundary

The first workflow slice tracks:

- project creation;
- idea capture;
- creative north star;
- discovery notes;
- unresolved decisions;
- character foundations;
- story architecture foundations;
- drafting readiness.

Later phases and publishing continue to use the existing specialist workspaces and the publishing readiness gate.
