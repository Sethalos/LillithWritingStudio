# Character system

Character Studio is Lillith's highest-priority domain. Its data must shape manuscript editing and analysis rather than live as isolated reference material.

## Character aggregate

Identity covers names, age, background, appearance, skills, limitations, habits, possessions, story role, status, and appearances. Psychology covers wound, fear, desire, need, false belief, personas, triggers, coping and defence mechanisms, attachment, boundaries, contradictions, guilt, pride, intimacy, violence, authority, responsibility, and loss of control.

Structured fields should remain optional where uncertainty is meaningful. Unknown is different from empty only when the workflow needs that distinction.

## Voice Lock

Each important character has a versioned Voice Lock describing vocabulary, syntax, formality, rhythm, education/professional/regional influence, humour, sarcasm, directness, profanity, verbal habits, metaphor preferences, interior narration, dialogue, silence, situational speech, and approved/rejected examples.

Relevant Voice Locks are pinned into dialogue and internal-narration context. Examples are author-owned evidence. The system must avoid reducing cultural or regional voice to phonetic caricature.

## Point-in-story state

Dynamic state uses manuscript-node validity intervals. It may include location, condition, injuries, illness, fatigue, clothing, equipment, carried objects, emotional state, recent events, immediate goal and fear, knowledge, incorrect beliefs, known/withheld secrets, promises, relationship/trust changes, compromises, losses, victories, unresolved conflict, and priorities.

Queries must be evaluated at a specific story position so future knowledge cannot leak into earlier scenes. Extracted state remains proposed until the author accepts it.

## Directional relationships

A relationship from A to B is distinct from B to A. It records public/private relationship, shared history, trust, affection, loyalty, respect, resentment, fear, dependency, power, secrets, obligations, tension, wants, misunderstandings, recent changes, and future conflict opportunities. Changes link to the scene or chapter where they occur.

## Character arcs

An arc records starting state, false belief, wound, external goal, internal need, pressure events, failed coping, escalating consequences, recognition, critical choice, sacrifice, transformation, and ending state. Beats link the plan to manuscript positions.

Analysis may flag stalled arcs, abrupt change, unearned reversal, missing transitions, repeated emotional beats, contradictory motives, forgotten conflicts, weak setup/payoff, disappearance gaps, and supporting characters without independent purpose. Findings must include evidence and suggested repair strategies.

## AI integration

Task-specific assembly selects only relevant characters and state. Dialogue review generally includes the speaker's Voice Lock, applicable state, addressee relationship, scene goal, author profile, and nearby evidence. Character information is inspectable in the context package and never treated as prompt text with authority over system instructions.

## Current implementation boundary

Identity, psychology, Voice Lock, states, relationships, arcs, persistence, and context inclusion exist. Follow-up work should improve completeness, provenance, appearance tracking, extraction review across all character fact types, and focused Character Studio workflows before adding decorative visualization.
